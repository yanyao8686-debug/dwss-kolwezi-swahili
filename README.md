# DWSS 科卢韦齐斯瓦西里语助手

当前版本：**0.6.2**。本仓库通过 GitHub Actions 自动发布 PWA 到 GitHub Pages。

## 更新到 0.6.2（本次只需上传一次新包）

1. 下载本对话提供的 `DWSS_PWA_0.6.2_GitHubPages_发布包.zip`。
2. 在仓库主页点击 **Add file → Upload files**。
3. 把 ZIP 文件本身上传到仓库根目录，不要解压，也不要修改文件名。
4. 点击 **Commit changes**。
5. 打开 **Actions**，等待 `Deploy DWSS PWA to GitHub Pages` 显示绿色勾号。

GitHub Pages 已经设置为 GitHub Actions，本次不需要再进入 Settings 更改设置。

正式网址：
https://yanyao8686-debug.github.io/dwss-kolwezi-swahili/

## 0.6.2 功能

- 使用你最新提供的 DWSS 蓝色地球图片作为封面和桌面图标。
- 当地加丹加斯瓦西里语中文谐音词条优先匹配。
- 当当地词条缺失时，使用 598 项法语辅助词语/短语补位；每段法语都会同时显示法语原文和中文近似读音，并标注“法语代替”。
- 法语辅助表不是完整法语词典；未收录内容会提示，不编造。
- 可自行新增、编辑、删除当地斯语词条；也可添加法语备用表达，并手动修正法语中文近似读音。
- 支持词典查询、收藏、历史、个人词库备份/恢复和离线缓存。

## 手机安装

- Android：Chrome 打开正式网址，首次联网加载完成并显示“离线资源已缓存”后，从浏览器菜单选择“安装应用”或“添加到主屏幕”。
- iPhone：Safari 打开正式网址，首次联网加载完成并显示“离线资源已缓存”后，点击“分享 → 添加到主屏幕”。
- 更新版本后，首次需联网重新加载，让新版本缓存完成；然后再断网使用。

## 自己添加新词

进入“词库维护”：
- 填写中文意思。
- 让科卢韦齐当地同事实际发音，再填写当地斯语中文近似读音。
- 当地拼写只有经当地使用者确认后才填写。
- 当地词条缺失时，可填写法语备用表达；软件会同时显示法语和中文近似读音。
- 法语读音可请会法语的人校对后手动修改。
- 点击保存，即可参与后续中文短句和长句匹配。

换手机或清除浏览器数据前，请在“备份与恢复”导出个人词库。个人词条保存在当前设备，不会自动跨设备同步。

## 准确性说明

原始两份资料主要提供中文近似读音，没有系统给出可核验的斯瓦西里语拉丁拼写，因此软件不伪造当地拼写。法语中文近似读音是辅助记忆提示，不是 IPA，也未逐条经过母语者核验；长句按词条匹配组合不等于完整语法翻译。重要安保、医疗和紧急表达请当地使用者确认。
