# DWSS 科卢韦齐斯瓦希里语助手

当前正式版本：**0.9.12**  
正式网址：https://yanyao8686-debug.github.io/dwss-kolwezi-swahili/

DWSS 面向刚果（金）卢阿拉巴省科卢韦齐及加丹加一带的日常与工作沟通，优先使用用户提供的本地词库资料。它是一个基于词条匹配、短语拼配和候选推荐的辅助工具，**不是 Google 翻译一类的神经网络整句翻译器**。

## 主要功能

- **翻译：** 输入中文短句或工作指令，优先匹配两份原始资料中的当地词条；已知词条按词头和短语匹配，缺词处明确标记。
- **人工选择候选：** 缺少精确词条时显示人工整理的近义/场景候选或字面相关候选。候选不会自动替换；由使用者点击“替换并重译”后才应用。
- **词典：** 可按中文、当地读音、拼写和法语备用表达搜索内置、个人及云端共享词条。
- **个人词库：** 可新增、编辑、删除自己的词条，保留来源、备注、分类；支持导出与合并恢复备份。
- **云端共享：** 新增合格词条后自动提交共享库；云端在线时其他设备可获取更新。断网时进入本机待同步队列，恢复网络后自动补传。每条记录有唯一提交编号，重试时避免重复插入。
- **离线 PWA：** 首次联网并完成缓存后，可使用已缓存的词库和功能；联网后检查软件更新。

## 添加与共享新词

1. 在“添加新词”中填写中文意思。
2. 当地斯语中文谐音应来自科卢韦齐当地实际发音；当地拼写只在经当地使用者核实后填写。
3. 保存后，具备当地中文谐音的斯语词条会自动进入公共共享词库；拼写可暂缺。只有拉丁拼写而没有当地读音的记录会保留在个人词库，并提示补充，不会猜造读音。
4. 法语备用表达会单独标记为法语，不冒充当地斯语。
5. “来源”和个人“备注”保留在本机，不随个人词条自动上传。公共共享面板中的“公开备注”会对所有共享词库用户可见，禁止填写同事姓名、电话、证件号、门禁信息或公司内部敏感内容。

升级前已经存在的旧个人词条不会被自动批量公开。需要共享某条旧词时，在原词条上编辑并保存一次，即可触发共享；无需重新新增一条。

## 准确性与安全边界

- 原始词库主要提供中文近似读音，不是国际音标（IPA）；完整拉丁拼写并非每条都有。
- 中文谐音和当地口语是否准确，仍需科卢韦齐母语者逐条核验。软件不能仅凭文字保证当地发音、语法、时态或人称词缀正确。
- 候选只用于辅助判断；“字面相关”不等于同义词。替换前请结合语境。
- 安保、车辆放行、人员盘查、医疗和紧急指令必须由当地同事确认后再使用，不能把软件输出当作正式命令翻译。
- 共享词库是公开共建机制；提交内容会被其他使用者读取。当前公开写入模式尚需配套人工审核或防垃圾机制，严禁上传个人或公司敏感资料。

## 手机安装与更新

- Android：用 Chrome 打开正式网址，首次联网完成缓存后，从浏览器菜单选择“安装应用”或“添加到主屏幕”。
- iPhone：用 Safari 打开正式网址，选择“分享 → 添加到主屏幕”。
- 更新后保持联网重新打开；如未看到新版本，可点击“检查更新”或刷新一次。待资源缓存完成后再断网使用。

## 备份

更换手机、清理浏览器站点数据或卸载应用前，进入“添加新词”页面的备份区域，生成并保存个人词库 JSON。收藏和查询历史是本机数据，建议同时保留重要内容的单独备份。

## 发布维护

GitHub Actions 工作流会在相关源码或发布脚本更新后构建并部署 GitHub Pages。每次发布以 Actions 中 Deploy to GitHub Pages 任务成功为准。
