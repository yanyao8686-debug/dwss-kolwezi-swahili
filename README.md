# DWSS 科卢韦齐斯瓦西里语助手

当前版本：**0.6.2**。本仓库通过 GitHub Actions 自动发布 PWA 到 GitHub Pages。

## 更新到 0.6.2（本次只需上传一次新包）

1. 下载本对话提供的 `DWSS_PWA_0.6.2_GitHubPages_发布包.zip`。
2. 在仓库主页点击 **Add file → Upload files**。
3. 把 ZIP 文件本身上传到仓库根目录，不要解压，也不要修改文件名。
4. 点击 **Commit changes**。
5. 打开 **Actions**，等待 `Deploy DWSS PWA to GitHub Pages` 显示绿色勾号。

GitHub Pages 已经设置为 GitHub Actions，这次不需要再进入 Settings 更改设置。

正式网址：
https://yanyao8686-debug.github.io/dwss-kolwezi-swahili/

## 0.6.2 本次功能

- 更换为 2026-10-26 用户提供的新 DWSS 封面和桌面图标。
- 当地加丹加斯瓦西里语中文谐音词条优先匹配。
- 当当地词条缺失时，使用 598 项法语辅助词语/短语补位；每一段法语同时显示法语原文及中文近似读音，并明确标记“法语代替”。
- 法语辅助表不是完整法语词典；仍未收录内容会提示，不编造。
- 支持自行新增、编辑、删除当地斯语词条；可添加法语备用表达并手动修正法语中文近似读音。
- 支持收藏、历史、备份/恢复及离线缓存。

## 手机安装

- Android：Chrome 打开正式网址，首次联网加载完成并显示“离线资源已缓存”后，从浏览器菜单选择“安装应用”或“添加到主屏幕”。
- iPhone：Safari 打开正式网址，首次联网加载完成并显示“离线资源已缓存”后，点击“分享 → 添加到主屏幕”。
- 更新版本后，首次需要联网重新加载，让新版本缓存完成；随后才可再次离线使用。

## 自己添加当地新词

进入“词库维护”：
- 填写中文意思；
- 让科卢韦齐当地同事实际发音，再填写中文近似读音；
- 当地拼写只有经当地使用者确认后才填写；
- 缺少当地斯语时可填写法语备用表达，软件显示法语及自动生成的中文近似读音；
- 法语读音可请会法语的人校正后手动修改；
- 点击保存，立即参加后续查询和短句匹配。

换手机或清除浏览器数据前，在“备份与恢复”导出个人词库并保存；个人词条不会自动跨设备同步。

## 重要准确性说明

原始两份资料主要提供中文近似读音，没有系统给出可核验的斯瓦西里语拉丁拼写，因此软件不伪造当地拼写。法语中文近似读音是辅助记忆的读音提示，不是 IPA，也未逐条经过母语者核验；法语连读有特定适用/禁止条件，自动拼写转读不能完整覆盖。涉及安全、纪律、医疗及紧急指令时，请当地使用者确认。法语连读参考：Académie française 与 TV5MONDE。

本仓库和 Pages 网站公开可访问；个人词条、收藏和历史保存在各自手机本地，不自动同步。
