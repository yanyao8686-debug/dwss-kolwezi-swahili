# DWSS 科卢韦齐斯瓦西里语助手

当前版本：**0.6.3**。本仓库通过 GitHub Actions 自动发布 PWA 到 GitHub Pages。

## 更新到 0.6.3

1. 下载本对话提供的 `DWSS_PWA_0.6.3_GitHubPages_发布包.zip`。
2. 在仓库主页点击 **Add file → Upload files**。
3. 把 ZIP 文件本身上传到仓库根目录，不要解压，也不要修改文件名。
4. 点击 **Commit changes**。
5. 打开 **Actions**，等待 `Deploy DWSS PWA to GitHub Pages` 显示绿色勾号。

GitHub Pages 已设置为 GitHub Actions，不需要再进入 Settings 修改。

正式网址：
https://yanyao8686-debug.github.io/dwss-kolwezi-swahili/

## 0.6.3 功能与匹配顺序

- 使用用户提供的 DWSS 蓝色地球图片作为封面和图标。
- 第一优先级：原始两份资料中的加丹加斯瓦西里语中文谐音词条。
- 第二优先级：精确词条缺失时，尝试程序中明确列出的近义当地词条，例如“检查”可用词库已有的“查看”替代。逐段详情会说明原词和采用的词条。
- 第三优先级：当地词库没有合适词条时才用法语补位。主体只显示法语中文近似读音，并在旁边标注“（法语）”；法语原文收在可展开的辅助区域。
- 若仍未收录则明确提示，不编造翻译。
- 支持自定义当地词条、法语备用表达、读音修正、收藏、历史、备份/恢复及离线缓存。

近义替代是有限的实用近义表达，不保证在所有上下文中完全同义。安保、车辆检查、设备检修等具体指令请当地使用者核验。

## 手机安装

- Android：Chrome 打开正式网址，首次联网加载完成并显示“离线资源已缓存”后，从浏览器菜单选择“安装应用”或“添加到主屏幕”。
- iPhone：Safari 打开正式网址，首次联网加载完成并显示“离线资源已缓存”后，点击“分享 → 添加到主屏幕”。
- 更新后首次需联网重新加载，等新版本缓存完成后再断网使用。

## 自己添加新词

进入“词库维护”：
- 填写中文意思。
- 让科卢韦齐当地同事实际发音，再填写当地斯语中文近似读音。
- 当地拼写只有经当地使用者确认后才填写。
- 当地词条缺失时，可填写法语备用表达；主体结果显示法语中文近似读音并标注“（法语）”。
- 法语读音可请熟悉刚果（金）当地法语的人校正后手动修改。
- 保存后立即参与后续查询和短句拼配。

换手机或清除浏览器数据前，请在“备份与恢复”导出个人词库。个人词条保存在当前设备，不会自动跨设备同步。

## 准确性说明

原始两份资料主要提供中文近似读音，没有系统给出可核验的斯瓦西里语拉丁拼写，因此软件不伪造当地拼写。法语中文近似读音是辅助记忆提示，不是 IPA，也未逐条经过母语者核验；长句按词条匹配组合不等于完整语法翻译。重要安保、医疗和紧急表达请当地使用者确认。

本仓库和 Pages 网站公开可访问；请勿上传密码、访问令牌或个人敏感信息。
