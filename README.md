# DWSS 科卢韦齐斯瓦希里语助手

当前源码版本：**0.9.101**（Pages 线上发布状态以部署后的 VERSION.txt 和自动生成的发布核验记录为准）

DWSS 面向刚果（金）卢阿拉巴省科卢韦齐及加丹加一带的日常与工作沟通，优先使用用户提供的本地词库资料。它是一个基于词条匹配、短语拼配和候选推荐的辅助工具，**不是 Google 翻译一类的神经网络整句翻译器**。

## 主要功能

- **当前界面与自动更新（0.9.55）：** 翻译页是默认主界面；主导航保留“添加新词”“历史记录”两个切换按钮及“清空信息”操作，不单独显示“词库”按钮。内置词典与公共读音修订入口放在“添加新词”页面的次级操作中。自动更新在应用打开、回到前台或恢复联网时检查 Service Worker；切换版本前会保存翻译、新词及正在编辑的公共读音草稿。
- **原始词条补录：** 根据第二份 PDF 原始表格补回“笔—比各”“给我—刀呢莫挖”；第一份资料中“给我……—木尼白……”继续保留。第一份资料标注为法语的“笔—撕提lou（法）”只作为法语参考，不覆盖当地词条。

- **翻译：** 输入中文短句或工作指令，优先匹配两份原始资料中的科卢韦齐当地词条；每个中文词头只采用当前优先级最高的第一条当地读音，避免把多个备选读音拼成一次口语表达。当地斯语没有对应词条时，才按规则使用手动录入的法语中文谐音替代，并标明法语来源。
- **人工选择候选：** 缺少精确词条时显示人工整理的近义/场景候选或字面相关候选。候选不会自动替换；由使用者点击“替换并重译”后才应用。
- **词条引擎与公共读音维护：** 内置词典仍用于翻译匹配，但不单独出现在主导航。用户从“添加新词”里的“查找并修改已收录词条读音”进入内部查询页；已收录词头的公共中文谐音可通过服务端修正接口更新，并保留原始读音、修订版本及修改历史，支持恢复旧版本。完整短句在主翻译页修正时，更新该中文输入对应的唯一当前主结果，不再把纠错误当成新增候选；提交前显示原结果与新结果确认，成功后立即刷新主结果。其他当地读音单独作为候选，在主结果下方以横向滑动条展示，并标记“已确认 / 当地常用 / 待确认”；候选记录支持再次编辑、撤回、历史查看和恢复。服务端采用版本号检查，避免并发修改静默覆盖。
- **个人词库：** 可新增、编辑、删除自己的词条，保留来源、备注、分类；支持导出与合并恢复备份。
- **云端共享：** 新增合格词条后自动提交共享库；云端在线时其他设备可获取更新。断网时进入本机待同步队列，恢复网络后自动补传。每条记录有唯一提交编号，重试时避免重复插入。
- **离线 PWA：** 首次联网并完成缓存后，可使用已缓存的词库和功能；联网后检查软件更新。
- **自动更新与编辑状态保护（0.9.44、0.9.55）：** 应用启动、恢复前台或联网时检查 Service Worker；发现新版后自动下载、激活并刷新。切换时保留翻译输入、新词表单、当前子页面、词典搜索词和未提交的公共读音编辑内容，不清理本机个人词库及待同步队列。

- **版本 0.9.33 视觉修正：** 使用用户重新提供的方形 DWSS 蓝色地球封面，避免旧 HTML 题字叠加；翻译页两处标题改为火红橙色、加下划线，结果标题强制单行显示；移除“等待输入”旧提示，并更新 Service Worker 缓存版本以触发手机端更新。

- **版本 0.9.34 标题字号统一：** 翻译结果标题固定为 16px，与中文输入标题保持相同字号；保留火红橙色下划线和单行显示，并更新 PWA 缓存版本。


- **版本 0.9.57 未收录词条自动转入与双输入清空：** 主翻译检测到未收录中文后自动进入“添加新词”并预填第一条；输入法组合输入完成后才启动延时检测；不覆盖用户已有的新词草稿；保存一条后自动定位下一条未收录内容；“清空信息”同时清空主翻译内容和完整新词表单。
- **版本 0.9.58 同步状态提示去重：** 长说明只在新词表单状态区显示一次，顶部共享状态只显示简短状态；只有需要人工处理的失败或待同步状态才显示重试入口。
- **版本 0.9.69 原始词库恢复与启动提示：** 恢复两份原始资料的遗漏词条和来源记录，发布时校验压缩词库结构、词条数量、应用名称、公告关闭动作、资源与在线版本；首次启动公告可关闭，版本缓存和 PWA 身份保持一致。

## Android 与网页版本关系

Android APK 使用原生 WebView 外壳加载上述正式 HTTPS 网站；联网启动时，APP 与网页使用同一套页面、功能、共享词库、发音变体和翻译逻辑。网页功能发布后由 Service Worker 在线更新，**普通翻译、词库、发音、界面更新不要求重新下载 APK**；只有安卓原生外壳、权限、包名、图标或原生插件改变时才需要重新构建 APK。离线时使用本机已成功缓存的网页版本，首次安装或清除应用数据后必须先联网完成缓存。

**强制同步规则（长期维护要求）：** 每次网页功能变更都必须确认 Android WebView 能从同一正式网站取得该功能；共享数据使用同一 Supabase 项目和表；发音模块的加载顺序、Service Worker 缓存清单和版本必须检查；不得把普通网页发布误触发为 APK 重建。原生壳变化才运行 Android 构建与安装包回归测试。

## 添加与共享新词

1. 在“添加新词”中填写中文意思。
2. 当地斯语中文谐音应来自科卢韦齐当地实际发音；当地拼写只在经当地使用者核实后填写。
3. 保存后，具备当地中文谐音的斯语词条会自动进入公共共享词库；拼写可暂缺。只有拉丁拼写而没有当地读音的记录会保留在个人词库，并提示补充，不会猜造读音。
4. 如果中文意思已经有当地斯语读音，而你听到另一种不同发音，可在同一中文词头下补充新谐音。系统会先按完整拼音检查同音重复；若属于不同读法，会询问是否作为“当地发音变体”提交。原读音不会被覆盖。
5. 新提交的变体显示“用户提交 · 待确认”，可以用于反向发音查询，但不会冒充正式读音，也不会进入普通中文翻译。经当地使用者或维护人员核实后标记为“已确认”或“当地常见读法”，才进入正式翻译读音集合。拒绝的记录对普通用户隐藏。来源地区或听到的场景可以填写简短说明，不要填写人名、电话等个人资料。
6. 法语备用表达会单独标记为法语，不冒充当地斯语。
7. “来源”和个人“备注”保留在本机，不随个人词条自动上传。所有用户只通过主界面的“添加新词”入口录入，合格词条会自动同步到同一共享词库；不再设置独立的共享词库新增入口。请勿在词条内容中填写同事姓名、电话、证件号、门禁信息或公司内部敏感内容。

从 0.9.39 起，所有用户的个人词库会自动检查并补传已有的当地斯语词条：只要填写了当地斯语中文谐音，联网后就自动进入公共共享词库。新添加的斯语词条也会自动共享，不需要手动提交。已存在的完全相同词条会自动关联，不重复插入。只有拉丁拼写、没有当地中文谐音的词条不会冒充斯语读音上传；法语词条仍按法语来源单独标记。

## 准确性与安全边界

- 原始词库主要提供中文近似读音，不是国际音标（IPA）；完整拉丁拼写并非每条都有。
- 中文谐音和当地口语是否准确，仍需科卢韦齐母语者逐条核验。软件不能仅凭文字保证当地发音、语法、时态或人称词缀正确。
- 候选只用于辅助判断；“字面相关”不等于同义词。替换前请结合语境。
- 安保、车辆放行、人员盘查、医疗和紧急指令必须由当地同事确认后再使用，不能把软件输出当作正式命令翻译。
- 共享新增词条和公共读音修订会被其他使用者读取。公共读音修订由服务端校验是否为已收录词条，并限制字段长度和请求频率；这不能替代人工核对当地发音。请勿提交人名、电话、证件号、门禁信息或公司内部敏感资料。
